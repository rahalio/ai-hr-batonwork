# Batonwork — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Front-line worker in an augmented role

- As a network operations engineer, I want to see the recorded list of tasks the automation now handles for my role and correct it where it is wrong, so that decisions about my job are based on what actually happens rather than on a vendor's claim.
- As a support agent, I want to know how many hours a week the assistant has genuinely returned to me and where my employer has allocated them, so I can tell whether "you have more time for customers now" is true.
- As a worker whose main task was absorbed, I want a development route with a named owner and a date, so that being made more efficient does not quietly become being made surplus.
- As a worker, I want assurance that my task-level data cannot be used to rate my performance or justify discipline, so that recording the truth about absorption is safe for me.

### Team leader

- As a team leader, I want the task inventory for my team maintained from systems we already run plus a short monthly confirmation, so that I am not keeping a second set of books.
- As a team leader, I want to allocate reclaimed hours explicitly to customer conversations, case judgment or learning time, so that the capacity does not vanish into the backlog before I have decided anything.
- As a team leader, I want to start a handover — this person has peaked on this work, move them up — and have the system carry the development, mobility and evidence steps, so that the conversation I have informally today produces a record.
- As a team leader, I want to be warned when my team's reclaimed capacity has gone unallocated for a cycle, so that I find out before the quarterly review does.

### Workforce planning analyst

- As a workforce planning analyst, I want reconciliation between the hours an automation business case promised and the hours the task records show, so that next year's plan is built on measured rather than asserted productivity.
- As a workforce planning analyst, I want role-level views of which task families are absorbed, partially absorbed or untouched, so that I can identify where redeployment supply and skills demand actually meet.
- As a workforce planning analyst, I want adverse impact testing on every proposed selection pool before it is communicated, so that a plan is not derailed by a fairness problem discovered at the consultation meeting.

### Employee representative

- As a works council member, I want access to the same task-change, headcount and training records management uses, so that consultation is a negotiation over facts rather than over slides.
- As an employee representative, I want to lodge and track an objection on behalf of a member whose absorption record or non-selection reasons look wrong, so that the challenge route is real and time-boxed.

### HR compliance administrator

- As an HR compliance administrator, I want to configure per-jurisdiction consultation triggers, thresholds and timetables, so that a change affecting a German site does not follow the process designed for an Irish one.
- As an HR compliance administrator, I want an immutable history of every absorption record, allocation decision, selection rationale and objection outcome, so that a tribunal bundle can be produced without reconstructing events from email.
- As an HR compliance administrator, I want to enforce that task telemetry is excluded from performance and payroll integrations, so that the purpose limitation we promised the works council is a system property and not a policy statement.
